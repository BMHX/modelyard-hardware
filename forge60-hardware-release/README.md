# Forge 60 Hardware Release

Forge 60 is a compact high-power flashlight with a constant 60 W / 10,000 lm output mode.

## Boards

- `mainboard-v2/`: recommended main control and power board.
- `led-board-5050/`: 5050 LED board.
- `source/`: EasyEDA Pro source project.

## Included Files

Each released board includes:

- `*-gerber.zip`: PCB fabrication files.
- `*-bom.xlsx` and `*-bom.csv`: bill of materials.
- `*-pick-and-place.xlsx` and `*-pick-and-place.csv`: SMT placement / centroid files.
- `*-schematic.pdf`: schematic PDF.
- `*-pcb-preview.pdf`: PCB preview / assembly reference exported from EasyEDA Pro.

## Source

- `source/forge60-easyeda-pro-source.epro2`: EasyEDA Pro source project.

## Board Thickness

- Mainboard: 1.0 mm
- LED board: 1.6 mm
